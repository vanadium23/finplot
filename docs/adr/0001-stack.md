# Стек Finplot — ADR-0001

- Дата: 2026-11-10
- Статус: accepted

## Context

Бриф finplot v1 (accepted): frontend-only игра «дорисуй график» на
реальных финансах ~100 US-компаний; сервер только раздаёт статику;
платформа 2 CPU / 3.8 GB RAM (общая); стенд `<ip>:41007`; приёмка —
зелёный CI (пока нет — локальный `make test` + живой стенд, см.
Consequences).

## Decision

- **Vanilla HTML/CSS/JS + SVG, без сборки.** Одна страница `index.html`,
  приложение — ES-модули без фреймворка, график — рукописный SVG
  (сюжет, оси, свободное рисование полилинией). Ноль рантайм-зависимостей.
- **Датасет: JSON в репо.** `tools/build_dataset.py` (python3 stdlib)
  ходит в SEC EDGAR XBRL, валидирует ряды, пишет
  `public/data/companies.json`. Обновление датасета = перезапуск
  скрипта + перекоммит (не-цель брифа: авто-обновление).
- **BDD-харнесс: playwright-bdd** (bdd-standard v1: RU-Gherkin,
  `tests/features/{logic,e2e}`, Make-контракт, HTML-отчёт `testing/`,
  smoke `make check-stand`). Логика игры (скоринг, выбор среза,
  валидация ряда) — чистые модули, тестируемые в `@logic` без браузера.
- **Стенд: nginx:alpine, статику отдаёт bind-mount репо** (паттерн
  taste-map: compose в `faber-hermes-config/infra/finplot/`, порт 41007,
  регистрация в PORTS.md тем же коммитом). mime.types с `mjs` —
  по уроку taste-map-v2.

## Alternatives considered

- **Vite + React/Svelte**: сборка и фреймворк ради одной страницы —
  лишняя масса под платформенные ограничения; отвергнуто.
- **D3/Charting-библиотеки**: график — это полилиния + оси + drag,
  ~200 строк SVG руками; зависимость не оправдана.
- **SSR/бэкенд**: бриф прямо требует frontend-only; «Другие» —
  помеченная локальная заглушка.

## Consequences

- Ноль сборки = деплой копированием файлов; CI может проверять
  lint+test без node-билда.
- **CI пока не существует**: текущий PAT не может пушить
  `.github/workflows/*` (запарковано; Иван добавляет workflow через
  web UI). До появления CI приёмка = локальный `make test` зелёный +
  живой стенд `make check-stand` зелёный.
- Датасет в git: диффы обновления большие, но редкие и обзорные.

## Reopen conditions

- Появится второй режим (daily с общим расписанием) или реальный
  «Others» (агрегация игроков) — потребует бэкенда, пересмотреть ADR.
- Сложность UI перерастёт ~1500 строк JS — пересмотреть фреймворк.
