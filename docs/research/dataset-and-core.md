# Research: датасет SEC EDGAR и ядро игры (finplot)

Дата: 2026-11-10. Живые пробы (кэш: ~/.hermes/cache/scratch/finplot-probe/).
Всё, что ниже — проверено прогонами, не память.

## Источник данных

- `https://data.sec.gov/api/xbrl/companyconcept/CIK<10>/us-gaap/<Tag>.json`
  — бесплатно, без ключей; требует User-Agent; ~3 rps на одно соединение
  (каждый запрос = новый TLS) — пул в 8 потоков даёт ~x6.
- Фильтр FY-значений: `form=10-K`, `fp=FY`, длительность периода 330–380 дн.;
  при конфликте (рестайты) побеждает более поздняя `filed`.
- Цепочки тегов (порядок = приоритет; далее только заполняют дыры):
  - выручка: RevenueFromContractWithCustomerExcludingAssessedTax → Revenues
    → SalesRevenueNet → SalesRevenueGoodsNet;
  - прибыль: NetIncomeLoss → ProfitLoss (ProfitLoss критичен для старых
    10-K до ~2009: без него KO/CAT/IBM теряют хвост).
- **Дедуп по фискальному году, не по дате конца**: FY-end гуляет на дни
  (TSN 2009-09-30 → 2009-10-03; DE, BBY, JCI — те же 1–35-дневные сдвиги)
  — ключ = год конца периода, иначе валидатор видит «дыру 3 дня».
- Валидация ряда: ≥12 точек, шаг ровно 1 год, без нулей/None внутри
  (нулевая прибыль разрешена только... не разрешена нигде, кроме первой
  точки; отрицательные значения — валидны, убыток = реальный факт).

## Выборка (живые числа, 2026-11-10)

- S&P 500 (Wikipedia «List of S&P 500 companies»): 503 компании, у каждой
  в таблице есть CIK (колонка Weight исчезла из страницы — кап-ранжирование
  оттуда невозможно; stockanalysis.com отдаёт клиентскую пагинацию, одна
  страница = 65 строк).
- Ранжирование: по последней FY-выручке из EDGAR (честный фундаментальный
  размер, из нашего же источника). 488/503 имеют хоть какой-то ряд выручки.
- Пул топ-160 после дедупа по CIK (GOOGL/GOOG — один CIK 1652044!):
  **126 из 160 проходят валидацию по ОБОИМ метрикам** — первые 100 валидных
  набираются внутри топ-~120. AC брифа «≥100 компаний × 2 метрики» достижим.
- Классы отказов: свежие IPO/спиноффы (UBER 9 точек, GEV 4, CRH 5),
  дыры цепочки тегов (MPC 2015→2018, AXP 2010→2017, JNJ 2008→2010 —
  годы под тегами вне нашей цепочки), короткие ряды (TGT ni=11, TJX ni=11).

## Формулы ядра (пин карточки FP-002, числа — tools/spec_fp002_probe.py)

- `pickRound`: r1 → компания floor(r1·n), r2 < 0.5 → revenue;
  cutoffIndex = floor(0.6·n); показаны индексы 0..cut−1, рисуем cut..n−1.
- `score`: avgMiss = mean(|guess−actual|) по скрытой части;
  points = round(100·max(0, 1 − avgMiss/(yMax−yMin)));
  ось = min/max ПОЛНОГО факта (показанное + скрытое), чтобы факт влезал
  на reveal. Пример (DRAMA, flat-25): misses [0,3,5,6,7,8,9],
  avgMiss = 38/7 = 5.428571…, ось 16..100, points = 94.
- `pseudoOthers`: others[0] = факт (якорь);
  others[i] = actual[i] + u·0.15·|actual[i] − actual[i−1]|, u = 2·rng()−1.
  Семантика Δ: от предыдущей ТОЧКИ РЯДА (не через одну — первая версия
  генератора считала через якорь и вылезала из полосы; поймано чекером
  пробы до заморозки).
- Композиция rng: один seeded mulberry32 на сессию; pickRound = 2 числа,
  pseudoOthers = len(hidden)−1, следующий pickRound — следующие 2.

## Харнесс

- e2e: playwright `webServer` на `public/` (python3 -m http.server или
  npx serve) — НЕ file:// (Chromium блокирует ES-модули и fetch по CORS;
  урок taste-map-v2 не нужен, у нас есть статический сервер с первого дня).
- logic-проект гоняет чистые модули без браузера.
- nginx-стенд: mime.types обязан знать `mjs` (урок taste-map-v2:
  application/octet-stream убивает ES-модули при зелёном curl /).
