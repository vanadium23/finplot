# FP-002 — Ядро игры: спека (bdd: готова после ОК Ивана)

Карточка: docs/tasks.md#FP-002. Фикстура: test/fixtures/mini-companies.json
(заморожена). Числа сняты живым прогоном tools/spec_fp002_probe.py
(python-референс формул карточки, mulberry32) — в спеке допуски ±0.001.

Композиция rng (пин): один seeded rng на сессию; pickRound берёт 2 числа
(компания floor(r1·n), метрика r2 < 0.5 → revenue); pseudoOthers берёт
следующие len(hidden)−1 чисел; следующий pickRound — следующие 2.

## Сценарии

### 1. Первый раунд дня
Given фикстура из 5 компаний и rng с seed 42
When движок выдаёт раунд
Then компания ACME, метрика «выручка», показаны годы 2005–2013 (9 точек),
рисовать 2014–2020 (7 лет), cutoffIndex = 9

### 2. Следующий раунд ленты
Given тот же rng после раунта 1
When игрок жмёт «Следующий график»
Then новый раунд: компания STABLE, метрика «выручка»

### 3. Точный ответ — максимум очков
Given раунд DRAMA, выручка (факт скрытой части [25, 22, 20, 19, 18, 17, 16])
When игрок нарисовал [25, 22, 20, 19, 18, 17, 16]
Then avgMiss = 0 и points = 100

### 4. Промах считается в единицах метрики
Given раунд DRAMA, выручка, ось Y от 16 до 100
When игрок нарисовал [25, 25, 25, 25, 25, 25, 25]
Then промахи по годам [0, 3, 5, 6, 7, 8, 9], avgMiss = 38/7 ≈ 5.4286,
points = 94

### 5. Заглушка «Другие» честная и детерминированная
Given раунд SMALL, выручка, rng с seed 7 после 2 чисел pickRound
When движок генерирует линию «Другие (заглушка)»
Then линия [8.0, 8.8913, 9.9246, 10.8964, 11.8906] (±0.001), первая точка
равна факту (якорь 8.0), каждая |others[i] − actual[i]| ≤ 0.15·|actual[i] −
actual[i−1]| + 0.001, линия не совпадает с фактом тождественно, повторный
прогон с тем же seed даёт ту же линию

### 6. [Негативный] Битый JSON
When loadDataset получает '{}'
Then бросает исключение, приложение не падает молча

### 7. [Негативный] Дыра в ряду
When в датасете компании не хватает одного года внутри ряда
Then loadDataset бросает исключение (fail-fast)

### 8. [Негативный] Ряд короче 12 точек
When у компании 11 годовых точек
Then loadDataset бросает исключение
